
# VOSC Activity-1: Tic Tac Toe

## About the Project
This project is a simple, interactive Tic Tac Toe game
developed as part of VOSC Activity-1.

Two players take turns marking X and O on a 3x3 board.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Two-player gameplay
- Interactive 3x3 game board
- Automatic winner detection
- Draw detection
- Highlighting of winning cells
- Restart Game button
- Responsive layout

## Project Structure
- index.html - Defines the game structure
- style.css - Styles the game interface
- script.js - Implements the game logic
- README.md - Documents the project

## How to Run
1. Download or clone this repository.
2. Keep all three code files in the same folder.
3. Open index.html in a web browser.
4. Click any empty cell to play.

## How to Play
1. Player X starts first.
2. Player O plays after X.
3. Get three matching marks in a row, column, or diagonal to win.
4. If all nine cells are filled without a winner, the game is a draw.
5. Click Restart Game to play again.
